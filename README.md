# Data Structures in C

A collection of classic data structure implementations in C for learning and practice.

## Modules

| Module | Description |
|--------|-------------|
| [Linked List](./linkedlist/) | Singly linked list implementation |
| [Stack](./stack/) | Stack (LIFO) using linked list nodes |

## Building

Each module has its own directory with source files and a README containing build instructions and API documentation.

```bash
cd <module>/
gcc -Wall -Wextra -std=c11 *.c -o <output>
```

## Purpose

This repository is primarily for **university assignments and practice**, not for production use.
